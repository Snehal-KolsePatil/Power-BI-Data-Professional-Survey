# Data Professional Survey Analysis – Power BI

An interactive **Power BI dashboard** created to analyze survey data from data professionals and understand trends related to roles, salaries, programming languages, job satisfaction, career switching and demographics.

# Project Overview

This project analyzes responses from data professionals to identify insights related to:

* Job roles in the data industry
* Salary ranges
* Favorite programming languages
* Industries people work in
* Job satisfaction
* Work-life balance
* Career switching into data
* Difficulty of entering the data field
* Education and demographics
* Important factors when looking for a new job

# Tools & Technologies

* Power BI Desktop
* Microsoft Excel
* Data Cleaning & Transformation
* Data Visualization
* Interactive Dashboard Design

# Key Analysis

The dashboard provides insights into:

* Distribution of data professionals by job role
* Salary comparison across roles
* Most preferred programming languages
* Average job satisfaction
* Work-life balance
* Career transition into the data field
* Difficulty experienced while entering the data industry
* Geographic distribution of respondents

# Project Objective

The objective of this project is to transform survey data into an interactive and easy-to-understand dashboard that helps identify trends and patterns within the data professional community.

# Dataset

The dataset contains survey responses from data professionals.

The publicly shared dataset has been prepared to avoid exposing personal information.
